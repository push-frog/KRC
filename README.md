# KRC — Keenetic Route Manager Pro

Независимое десктоп-приложение для управления роутерами Keenetic по Telnet: статические маршруты, переадресация портов, системный монитор.

## Дисклеймер

Проект **не связан** с компанией Keenetic и не является официальным продуктом Keenetic. Это сторонняя утилита.

Перед публикацией на GitHub вопрос задавали в техподдержку Keenetic; против публикации они не возражали. Это **не** официальное согласование, спонсорство или поддержка приложения со стороны Keenetic.

Keenetic® — торговая марка соответствующего правообладателя.

## Запуск

```bash
pip install -r requirements.txt
python keenetic.py
```

Telnet нужно включить на роутере: веб-интерфейс → Системные настройки → Опции.

Локальные настройки подключения сохраняются в `keenetic_settings.json` и в git не попадают.

## Структура

Точка входа не изменилась: `python keenetic.py`.

```
keenetic.py          # запуск GUI
krc/util.py          # маски, декодирование вывода
krc/client.py        # Telnet-клиент Keenetic
krc/dialogs.py       # диалоговые окна
krc/gui.py           # главное окно
```
