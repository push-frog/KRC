# KRC — Keenetic Route Manager Pro

Десктоп-приложение для Keenetic: Telnet (CLI) + HTTP RCI. Интерфейс на русском.

Неофициальная сторонняя утилита. К Keenetic Ltd. не относится и официальной поддержкой не является. Keenetic® — торговая марка правообладателя.

## Что умеет

**Подключение**
- Telnet (порт 23) к Keenetic OS, в т. ч. 5.x
- Логин/пароль, сохранение IP и логина в `keenetic_settings.json` (пароль в файл не пишется)
- Журнал команд на вкладке «Логи»

**Монитор**
- Модель, прошивка, hostname, uptime, WAN IP, DNS
- CPU / RAM / температура
- Трафик и состояние интерфейсов
- Список клиентов (DHCP / ARP / hotspot)
- Автообновление и сырой вывод CLI

**Маршруты**
- Просмотр статических IPv4 / IPv6
- Добавление и удаление правил
- Пакетный импорт `route add` / `ip route` из `.bat` / `.txt` (порции по 300 команд)
- Экспорт сетей в JSON-like: `"x.x.x.x/маска",`

**Переадресация портов**
- Список статических правил через HTTP RCI (`POST /rci/`, `show.rc.ip.static`) — работает на KeeneticOS 5, где нет `show ip static`
- Комментарии с кириллицей, выключенные правила (`[off]`), подмена порта (555 → 554)
- Живые NAT-сессии / UPnP (отдельное окно)
- Фильтр, сырой JSON/вывод CLI

**Интерфейсы**
- Список интерфейсов роутера и их параметры

## Запуск

```bash
pip install -r requirements.txt
python keenetic.py
```

Telnet нужно включить на роутере: веб → Системные настройки → Опции.

Для списка переадресации портов нужен тот же пароль, что в веб-интерфейсе (RCI: NDM challenge + SHA256).

## Структура

```
keenetic.py          # точка входа
krc/gui.py           # окно и вкладки
krc/client.py        # Telnet-клиент
krc/rci.py           # HTTP RCI (переадресация, hotspot)
krc/sysmon.py        # парсеры монитора
krc/natparse.py      # запасной разбор CLI NAT
krc/util.py          # маски, CIDR, декодирование
krc/dialogs.py       # диалоги
```
